    Installation

    Overwatch ships as a single static binary. The installer detects your platform, verifies the download against the published checksums, and puts owatch on your PATH. No sudo, no admin rights.

    macOS and Linux

    curl -fsSL https://github.com/the-common-developers/owatch-releases/releases/latest/download/install.sh | sh

    Windows

    irm https://github.com/the-common-developers/owatch-releases/releases/latest/download/install.ps1 | iex

    Open a new terminal and check it worked:

    owatch --version

    Then authenticate with the credentials your operator provided:

    owatch login

    See Getting started for what happens next.

    What the installer does

    1. Detects your OS and CPU architecture (linux_amd64, linux_arm64, darwin_amd64, darwin_arm64, windows_amd64). Windows on ARM gets the amd64 build, which runs under emulation.
    2. Resolves the latest release from owatch-releases.
    3. Downloads the archive and verifies its SHA-256 against checksums.txt. If the digest does not match, or no digest is published for that archive, the installer stops and installs nothing.
    4. Installs to ~/.local/bin (macOS/Linux) or %LOCALAPPDATA%\Programs\owatch (Windows).
    5. Adds that directory to your PATH if it is not there already.

    Re-running the installer upgrades an existing install in place.

    Options

    Pipe arguments through to the script after -s --:

    url=https://github.com/the-common-developers/owatch-releases/releases/latest/download/install.sh

# Install a specific version
curl -fsSL "$url" | sh -s -- --version 0.1.3

# Install somewhere else
curl -fsSL "$url" | sh -s -- --dir /usr/local/bin

# Leave your shell profile alone
curl -fsSL "$url" | sh -s -- --no-modify-path

    The same options are available as environment variables, which is usually easier in CI:

    Variable Purpose Default
    OWATCH_VERSION Version to install latest release
    OWATCH_INSTALL_DIR Install directory ~/.local/bin
    OWATCH_NO_MODIFY_PATH Set to 1 to skip the PATH update unset
    OWATCH_BASE_URL Alternative download base URL (internal mirrors) GitHub releases

    On Windows, download the script and pass the matching parameters:

    $url = 'https://github.com/the-common-developers/owatch-releases/releases/latest/download/install.ps1'
& ([scriptblock]::Create((irm $url))) -Version 0.1.3

    Installing into a directory you do not own

    The installer never escalates on your behalf. To install somewhere like /usr/local/bin, run the whole script with the permissions it needs: curl -fsSL "$url" | sudo sh -s -- --dir /usr/local/bin.

    Installing in CI

    Pin the version so builds are reproducible, and skip the profile edit:

    - name: Install owatch
  run: |
    curl -fsSL https://github.com/the-common-developers/owatch-releases/releases/latest/download/install.sh | sh
    echo "$HOME/.local/bin" >> "$GITHUB_PATH"
  env:
    OWATCH_VERSION: 0.1.4
    OWATCH_NO_MODIFY_PATH: 1

    Reviewing the installer first

    Piping a script into a shell means trusting the source. The installer verifies what it downloads, but nothing verifies the installer itself — so if you would rather read it before running it:

    curl -fsSL https://github.com/the-common-developers/owatch-releases/releases/latest/download/install.sh -o install.sh
less install.sh
sh install.sh

    On Windows:

    irm https://github.com/the-common-developers/owatch-releases/releases/latest/download/install.ps1 -OutFile install.ps1
notepad install.ps1
./install.ps1

    Each release publishes the exact installer that shipped with it, so the copy you review is the copy you run.

    Uninstalling

    The uninstaller removes the binary and the PATH entry the installer added:

    curl -fsSL https://github.com/the-common-developers/owatch-releases/releases/latest/download/uninstall.sh | sh

    irm https://github.com/the-common-developers/owatch-releases/releases/latest/download/uninstall.ps1 | iex

    Your configuration and credentials are left in place, so reinstalling does not mean logging in again. To remove those too:

    curl -fsSL https://github.com/the-common-developers/owatch-releases/releases/latest/download/uninstall.sh | sh -s -- --purge

    $url = 'https://github.com/the-common-developers/owatch-releases/releases/latest/download/uninstall.ps1'
& ([scriptblock]::Create((irm $url))) -Purge

    If you installed somewhere other than the default, tell the uninstaller where: --dir /usr/local/bin (or -InstallDir on Windows).

    To do it by hand instead, delete the binary and remove the # Added by the Overwatch CLI installer lines from your shell profile:

    rm ~/.local/bin/owatch
rm -rf ~/.config/owatch          # credentials, if you want them gone

    Remove-Item "$env:LOCALAPPDATA\Programs\owatch" -Recurse
Remove-Item "$env:APPDATA\owatch" -Recurse      # credentials, if you want them gone

    Manual installation

    If you would rather not run a script at all, download the archive directly. Set the version and platform first — platform is one of linux_amd64, linux_arm64, darwin_amd64, darwin_arm64:

    VERSION=0.1.4
PLATFORM=darwin_arm64
BASE=https://github.com/the-common-developers/owatch-releases/releases/download/v${VERSION}

curl -LO "${BASE}/owatch_${VERSION}_${PLATFORM}.tar.gz"
curl -LO "${BASE}/checksums.txt"

# Verify (Linux)
sha256sum --check --ignore-missing checksums.txt
# Verify (macOS)
shasum -a 256 --check --ignore-missing checksums.txt

tar -xzf "owatch_${VERSION}_${PLATFORM}.tar.gz"
install -m 755 owatch ~/.local/bin/

    On Windows, download owatch_<version>_windows_amd64.zip from the releases page, check its hash against checksums.txt with Get-FileHash, extract owatch.exe, and place it on your PATH.
